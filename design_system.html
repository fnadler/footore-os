Bandeiras

Imagens de país e clube servidas como SVG 4:3 via CDN. PNGs locais exclusivos do seletor de idioma. Renderizadas em 6 tamanhos segundo o contexto de exibição.

Fonte e formato
API / CDN — SVG 4:3

Retornado em respostas de API — country.flag, nationalities[n].flag. SVG vetorial escalável, proporção 4:3 (landscape).

// Country interface — src/types/index.ts
interface Country {
  name?: string;
  flag?: string; // URL completa via API
  code?: string;
}

// Padrão de URL
https://storage.googleapis.com/rdf_static/
  flags/4x3/{country-code}.svg

// Exemplos
/flags/4x3/br.svg  → Brasil
/flags/4x3/ar.svg  → Argentina
/flags/4x3/de.svg  → Alemanha
