# Textos das features (Cláusula Sexta — coluna esquerda)

Rótulos **literais** da primeira coluna da tabela de features. NÃO resumir; copiar exatamente.
O valor de cada linha (coluna direita) vem de `planos.md`, pela chave `perfil + plano`.

Cabeçalho da tabela: **"PLANO FOOTLINK SCOUT <PLANO> - FEATURES"** | **"PLANO ANUAL"** (ou
"PLANO MENSAL" conforme o pedido).

Primeira linha sempre: **"Licenças Contempladas no Plano"** com o número por extenso
(ex.: "04 (quatro)"; incluir gratuitas quando houver: "20 (vinte) licenças + 01 (uma) licença
Feminino gratuita"). Quando o clube fecha por valor mensal composto, os contratos recentes colocam
o mensal nessa linha (ex.: "04 (quatro) – Pagamento mensal de R$ 1.300,00").

## CLUBES (lista condensada — ordem exata)

1. Meu Clube (com gestão de elenco, perfil com minutagem por idade, gestão de contratos, gestão de mercado)
2. Meu Feed (com alertas de registro no BID e FootNews)
3. Footlink Originals (conteúdo em vídeo com análise de mercados internacionais)
4. Busca de Atletas (acesso a base de dados com aproximadamente 600 mil atletas, masculino e feminino, desde os 7 anos de idade)
5. Perfil de Atletas (visualização de dados de contrato, carreira, desempenho, jogos com recursos para geração de relatórios, registro de avaliações e anotações sobre o atleta. Para atletas do clube, pode publicar vídeos e relatórios para qualificar apresentação do atleta)
6. Competições (visualizações de dados de competições, com o maior acervo de dados de competições de base organizadas por federações e CBF)
7. Projetos (organização do workflow de análise de mercado com geração de relatórios em formato de time sombra)
8. Monitoramento (registro dos atletas monitorados para recebimento de atualizações, organizar em listas e registrar informações)
9. Avaliações (registro de avaliações de atletas na plataforma, com relatórios em lista e gráficos)
10. Mercado de Transferências (anunciar atletas sem contrato e visualizar necessidades dos clubes, podendo oferecer atletas e gerenciar negociações)
11. Chat Integrado (ferramenta de comunicação com clubes e agentes) → valor "Recebe e envia mensagens para clubes clientes Footlink"
12. Agências Listagem de agentes clientes do Footlink com seus atletas agenciados

> Nota: alguns contratos recentes (Pantanal, Paysandu) trazem no item 5 a redação "Para atletas
> agenciados" — é copy-paste do texto de agente. O correto para clube é "Para atletas do clube"
> (usado acima). Sinalizar ao revisar se o cliente exigir espelhar o template deles.

## API (só quando o produto contratado incluir API)

**Objeto (Cláusula Primeira, item ii):** "comercialização da Licença de Acesso temporário da
Interface de Programação de Aplicação/Application Programming Interface (API) do software FOOTLINK".
A PI (2ª) e a suspensão por inadimplência (9ª) também passam a citar "e sua interface API".

**Cláusula Sexta — segunda tabela separada**, logo após a tabela de features, cabeçalho
"PLANO ACESSO À API DO FOOTLINK" | "PLANO ANUAL", com o texto:
"O acesso à API do Footlink permite a utilização dos dados da plataforma integrado a outras soluções
próprias ou terceiras, enriquecendo os dados do clube para análise. A API do Footlink fornece os
seguintes dados: Competições; Atletas monitorados; Atletas inseridos pela organização; Avaliações;
Relatórios; Projetos." → valor: "Pagamento mensal no valor de R$ X".

**Dois modelos de cobrança da API** (escolher pelo pedido):
- **Combinado (padrão recente — Londrina):** o valor mensal da API é somado ao do software num
  **boleto único**. Cláusula Sétima traz o total já somado (ex.: R$1.300 software + R$500 API =
  R$1.800/mês; total 12×). Uma tabela de parcelas só.
- **Boletos distintos (variante — Corinthians):** Cláusula Sétima discrimina parcela da API e
  parcela do software; §1º diz que se emitem boletos distintos por parcela.
